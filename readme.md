This travel itinerary app will allow users to plan domestic or international trips including:
 - Dates
 - Locations
 - Flights
 - Hotels
 - Activities

The app will allow users to sign-up, save their itineraries, and also collaborate on itineraries with invited users. (Web sockets?)

It will be a MERN stack application:
 - React
 - React Router
 - Redux
 - Node.js
 - Express.js
 - NoSQL

External APIs:
 - Amadeus for Developers
 - Mapbox
 - GeoDb Cities API
 - Foursquare Places API

The target demographic for the app is any and all uses that are interested in travel, with a attractive UI aimed to attract users in their 20s and 30s.
